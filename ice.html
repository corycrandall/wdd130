ICE challenges

Each challenge below has a short description, what I learned, and a link to the finished page. Links open in a new tab.

Apostle Spotlight

A spotlight panel of the First Presidency and the Quorum of the Twelve Apostles, with round portraits laid out over a full-panel background image.

What I learned

I practiced round images with border-radius and object-fit, a hover effect that grows each portrait with transform and transition, and a media query that lets the rows wrap on small screens.

Open Apostle Spotlight (opens in a new tab)

Prophet Card

A profile card for President Dallin H. Oaks with his portrait, key dates, a link to the Church website, and a quote.

What I learned

I practiced semantic HTML (main, h1, ul, img) and styled a card with borders, rounded corners, and a color scheme. I also added a Google Font for the quote and opened an outside link in a new tab with target and rel.

Open Prophet Card (opens in a new tab)

Favorite Devotionals

A table of my favorite devotionals with speaker, title, location, year, and a link to each one, plus a form for adding more.

What I learned

I built a table with thead, tbody, and th cells, then styled it with collapsed borders, striped rows, and a hover highlight. I also built a form with labels tied to inputs through for and id, several input types (text, number, url), and a two-column layout using CSS Grid.

Open Favorite Devotionals (opens in a new tab)

Happy Halloween

A Halloween page where the HTML was already written and I could only change the CSS.

What I learned

I saw how much an external stylesheet can change without touching the markup. I used element and id selectors, a sticky header, a Flexbox nav, a gradient background, an imported Google Font, alternating sections with :nth-of-type, and hover animations.

Open Happy Halloween (opens in a new tab)

Grid Flags

Six country flags (Chile, Denmark, Finland, Benin, Italy, and the Central African Republic) drawn with CSS Grid alone.

What I learned

I learned to build layouts with display: grid, using grid-template-columns and grid-template-rows with fr units, and to place boxes with grid-column and grid-row so they span several tracks. I used grid-gap to draw the crosses on the Danish and Finnish flags and clip-path to cut out a star.

Open Grid Flags (opens in a new tab)

Positioning Activity

Six activities where I matched the layout in an example image by editing only the stylesheet.

What I learned

I used CSS Grid for most of the layouts, overlapping boxes with grid-column and grid-row spans and layering them with z-index. The text-wrap activity taught me that float, not Grid, is the right tool for wrapping text around a box. I also added hover lift effects, a pop-in animation with @keyframes, and attribute selectors like [class^="red"] to style every box at once.

Open Positioning Activity (opens in a new tab)

Christ Art Gallery

A dark photo gallery of six paintings of Christ. Each thumbnail links to a larger version of the image.

What I learned

I built a three-column gallery with CSS Grid and used small 200 by 300 thumbnails that link to the big images so the page loads faster. I dimmed the pictures with filter: brightness() and saturate() and brought them back to full color on hover with a transition. I also swapped the mouse pointer for a custom image and added a Google Font for the title.

Open Christ Art Gallery (opens in a new tab)

Daily Feed Sign Up

A sign-up form for a daily scripture feed, with a hero banner, a row of scripture covers, and a close button.

What I learned

I practiced text, password, and email inputs, radio buttons, and checkboxes, with required validation and labels tied to inputs. I laid the form out with CSS Grid, placed the close button with position: absolute, and built the banner with a cover background image and text-shadow. It was also my first taste of JavaScript: the close button hides the form, and submitting shows the data that would be sent to the server.
